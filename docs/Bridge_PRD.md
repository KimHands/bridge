## 1. 서비스 개요

### 1.1 서비스 목적

Bridge는 정신건강 전문가를 찾기 어렵거나 찾기를 꺼리는 청년(19~34세)이 일상에서 감정을 기록하고, 개인 상태에 맞는 루틴을 수행함으로써 정서적 안녕을 스스로 관리할 수 있도록 돕는 디지털 웰니스 플랫폼이다.

### 1.2 핵심 가치

- **진입 장벽 낮춤**: 상담·병원 방문 없이 앱 내에서 자기 상태 파악 가능
- **개인화**: 자가평가 결과 + 일기 데이터 기반 맞춤형 루틴 제공
- **규제 안전성**: 진단·치료 기능 없음. "정보 제공 및 습관 형성 도구"로 포지셔닝

### 1.3 타겟 사용자

| 구분 | 내용 |
|------|------|
| 연령 | 19~34세 청년 |
| 주요 특성 | 정신건강 문제 인식하나 전문가 방문 꺼리는 그룹 |
| 주요 니즈 | 감정 기록, 일상 루틴 형성, 정서적 안녕 |

## 2. 온보딩 플로우

### 2.1 스플래시 화면

| 항목 | 내용 |
|------|------|
| 노출 시간 | 앱 실행 후 1.5초 |
| 구성 | 로고 + 슬로건 ("방치된 당신과 병원 사이의 다리, Bridge") |
| 이동 | 최초 실행 시 온보딩 슬라이드, 재실행 시 로그인 화면 |

### 2.2 온보딩 슬라이드

- 총 3장, 스와이프 또는 다음 버튼으로 이동
- 우측 상단 "건너뛰기" 버튼 제공

| 슬라이드 | 내용 |
|---------|------|
| 1장 | "내 감정을 매일 기록해요" — 키워드 일기 소개 |
| 2장 | "나만의 루틴으로 일상을 회복해요" — 루틴 시스템 소개 |
| 3장 | "당신의 변화를 함께 확인해요" — 리포트 소개 |

## 3. 인증 + 초기 설정

### 3.1 회원가입

**필드**
- 이메일 (중복 확인)
- 비밀번호 (최소 8자, 영문+숫자 조합)
- 닉네임

**약관 동의**
- 이용약관 (필수)
- 개인정보처리방침 (필수)
- 민감정보(정신건강 데이터) 수집·이용 동의 (필수) — 개인정보보호법 제23조 대응
- 마케팅 수신 동의 (선택)

**보안**
- 비밀번호: bcrypt (cost factor 12) 해시 저장
- 이메일: SHA-256 해시 저장 (`email_hash`), 원문은 별도 암호화 저장

### 3.2 로그인

- 이메일 + 비밀번호
- JWT 발급 (Access Token 1시간, Refresh Token 14일)
- 기존 사용자 → 홈 대시보드로 이동 (자가평가 생략)

### 3.3 AI 자가평가 (신규 가입 시 1회)

회원가입 완료 직후 진행. 기존 사용자 로그인 시 생략.

#### 3.3.1 PHQ-9 질문지

9개 문항, 각 0~3점 (전혀 없음 / 며칠 / 일주일 이상 / 거의 매일).

| 문항 | 내용 |
|------|------|
| 1 | 일 또는 여가활동에 흥미나 즐거움이 없음 |
| 2 | 기분이 가라앉거나 우울하거나 희망이 없음 |
| 3 | 잠들기 어렵거나 수면 유지 곤란 또는 너무 많이 잠 |
| 4 | 피곤함 또는 기운이 없음 |
| 5 | 식욕 감퇴 또는 과식 |
| 6 | 자신이 실패자라는 느낌, 자신을 실망시켰다는 느낌 |
| 7 | 신문을 읽거나 TV를 보는 것 등에 집중하기 어려움 |
| 8 | 다른 사람이 알아챌 정도로 말 또는 행동이 느리거나 반대로 너무 안절부절 |
| 9 | 자신을 해치거나 죽는 것이 낫겠다는 생각 |

> **주의**: 9번 문항에서 1점 이상 응답 시 "전문가와 상담해보는 것을 권장해요" 안내 팝업 표시. 진단 행위 없음.

#### 3.3.2 PHQ-9 구간 판정

| 구간 | 점수 | 내부 라벨 |
|------|------|------|
| 1구간 | 0~4점 | 안정 신호 |
| 2구간 | 5~9점 | 가벼운 신호 |
| 3구간 | 10~19점 | 살펴볼 신호 |
| 4구간 | 20~27점 | 집중 돌봄 신호 |

> 구간은 PHQ-9 표준 절단점에 기반한 **내부 루틴 배정 파라미터**이며, 임상 진단 범주가 아니다. 사용자에게는 점수·구간·라벨을 노출하지 않는다.

#### 3.3.3 원인 분류 질문 (PHQ-9 직후)

**Q1. 주원인** (1개 선택, 필수)
> "요즘 가장 힘든 이유가 뭔가요?"

- 잠을 잘 못 자고 있어요
- 학업이나 업무 때문에 지쳐요
- 미래와 진로가 막막해요
- 경제적인 걱정이 있어요
- 대인관계가 힘들어요
- 몸 상태가 안 좋아요
- 잘 모르겠어요

**Q2. 부원인** (1개 선택, 건너뛰기 가능)
> "그 외에 신경 쓰이는 게 있나요?"

- Q1 미선택 항목 동일 노출 + "없어요 / 건너뛸게요"

#### 3.3.4 초기 루틴 배정

PHQ-9 구간 × 주원인 조합으로 루틴 자동 배정.

| PHQ-9 구간 | 주원인 | 루틴 1 | 루틴 2 |
|-----------|--------|--------|--------|
| 1구간 | 수면 | 취침 전 스트레칭 10분 | 감정 일기 작성 |
| 1구간 | 학업·업무 | 하루 10분 산책 | 감정 일기 작성 |
| 1구간 | 진로·미래 | 오늘 잘한 일 1가지 적기 | 10분 독서 |
| 1구간 | 경제적 걱정 | 하루 10분 산책 | 감정 일기 작성 |
| 1구간 | 대인관계 | 10분 혼자 산책 | 감정 일기 작성 |
| 1구간 | 신체 건강 | 가벼운 스트레칭 10분 | 물 2L 마시기 |
| 1구간 | 모르겠음 | 하루 10분 산책 | 감정 일기 작성 |
| 2구간 | 수면 | 취침 전 4-7-8 호흡 5분 | 감정 일기 작성 |
| 2구간 | 학업·업무 | 오늘 할 일 1가지만 적기 | 5분 마음 챙김 호흡 |
| 2구간 | 진로·미래 | 오늘 할 수 있는 일 1가지 적기 | 5분 호흡 명상 |
| 2구간 | 경제적 걱정 | 5분 호흡 명상 | 감정 일기 작성 |
| 2구간 | 대인관계 | 감정 일기 작성 | 10분 혼자 산책 |
| 2구간 | 신체 건강 | 가벼운 스트레칭 5분 | 물 충분히 마시기 |
| 2구간 | 모르겠음 | 5분 호흡 명상 | 감정 일기 작성 |
| 3구간 | 수면 | 2분 복식호흡 | — |
| 3구간 | 학업·업무 | 오늘 할 일 1가지만 적기 | — |
| 3구간 | 진로·미래 | 2분 복식호흡 | — |
| 3구간 | 경제적 걱정 | 2분 복식호흡 | — |
| 3구간 | 대인관계 | 감정 일기 한 줄 작성 | — |
| 3구간 | 신체 건강 | 물 한 잔 마시기 | — |
| 3구간 | 모르겠음 | 2분 복식호흡 | — |
| 4구간 | 전체 공통 | 물 한 잔 마시기 | — |

**배정 원칙**
- 4구간은 원인 무관 고정 — 중증 상태에서 선택 자체가 부담이므로 최소 과제 1개로 통일
- 감정 일기는 1·2구간에만 포함 — 3·4구간은 회복 우선
- 사용자가 언제든 루틴 추가·삭제·교체 가능

## 4. 홈 대시보드

### 4.1 구성 컴포넌트

#### 기분 체크
- 5단계 이모지 선택 (😢 😔 😐 🙂 😊)
- 선택 시 `mood_score` (1~5) 자동 저장
- 하루 1회 기록. 이미 기록한 경우 현재 선택 상태 표시

#### 오늘의 루틴
- 오늘 배정된 루틴 카드 목록 (최대 2개)
- 완료 여부 체크박스
- "전체 보기" → 루틴 탭 이동

#### 이번 주 리포트
- 루틴 달성률 (%) + 기분 평균 이모지
- "자세히 보기" → 리포트 탭 이동

#### 오늘의 정보
- 매일 바뀌는 정신건강 정보 카드
- 예: "우울증은 의지의 문제가 아닌 뇌의 화학적 불균형이에요"
- 규제 대응: "정보 제공" 프레임 유지, 진단·치료 표현 없음

### 4.2 예외 처리

| 상황 | 처리 |
|------|------|
| 기분 체크 미완료 | 카드 상단에 "오늘 기분은 어때요?" 배너 표시 |
| 루틴 없음 | "아직 루틴이 없어요. 추가해보세요!" + 루틴 탭 이동 버튼 |
| 리포트 데이터 부족 (7일 미만) | "데이터를 쌓는 중이에요 (N일 남음)" 표시 |

## 5. 일기 탭

### 5.1 일기 작성 플로우

#### 5.1.1 1단계: 기분 이모지 확인

- 홈에서 선택한 `mood_score` 상단에 표시
- 미선택 시 일기 탭 진입 시 이모지 선택 요청

#### 5.1.2 2단계: 감정 키워드 선택

**공통 키워드 풀 (8개)**

| 키워드 | 근거 척도 |
|--------|---------|
| 우울한 | PHQ-9 핵심 증상 |
| 무기력한 | PHQ-9 (에너지 저하) |
| 불안한 | GAD-7 핵심 증상 |
| 초조한 | PHQ-9·GAD-7 공통 중개 증상 |
| 짜증나는 | GAD-7 (과민성) |
| 외로운 | 청년 고립감 연구 핵심 변수 |
| 뿌듯한 | 긍정 정서 |
| 평온한 | 긍정 정서 |

**이모지별 하이라이트 (상단 2~3개 강조 노출)**

| 이모지 | 하이라이트 |
|--------|---------|
| 😢 매우 힘듦 | 우울한 · 무기력한 |
| 😔 힘듦 | 불안한 · 외로운 |
| 😐 보통 | 초조한 · 짜증나는 |
| 🙂 좋음 | 평온한 · 뿌듯한 |
| 😊 매우 좋음 | 뿌듯한 · 평온한 |

**선택 규칙**
- 최대 2개까지 복수 선택 가능
- 선택 시 해당 키워드에 맞는 세부 질문 팝업 등장

#### 5.1.3 3단계: 감정별 세부 질문 팝업

감정 키워드 선택 시 바텀 시트로 세부 질문 등장. 답변 선택 = 상황 키워드로 DB 저장.

**😢 우울한** — "지금 가장 힘든 게 뭔가요?"
- 아무것도 하기 싫고 의욕이 없어요
- 나 자신이 쓸모없다는 느낌이 들어요
- 미래가 막막하고 희망이 없어요
- 이유를 모르겠어요

**😔 무기력한** — "무기력함이 어디서 오는 것 같아요?"
- 잠을 제대로 못 잤어요
- 몸이 너무 피곤하고 기운이 없어요
- 뭘 해도 집중이 안 돼요
- 실패하거나 좌절한 일이 있었어요

**😟 불안한** — "무엇 때문에 불안했나요?"
- 학업이나 업무 성과가 걱정돼요
- 미래나 진로가 불확실해요
- 돈이나 경제적인 상황이 걱정돼요
- 누군가와의 관계가 불편해요
- 이유 없이 그냥 불안해요

**😤 초조한** — "오늘 초조함을 느낀 상황은요?"
- 해야 할 일이 너무 많았어요
- 중요한 평가나 발표를 앞두고 있어요
- 기다리는 결과가 있어요
- 시간이 부족하다는 압박감이 들었어요

**😠 짜증나는** — "오늘 짜증이 났던 원인이 뭔가요?"
- 사람 때문에 감정이 소모됐어요
- 일이나 공부가 뜻대로 안 됐어요
- 몸 상태가 안 좋았어요
- 과민하게 반응한 것 같아요

**😞 외로운** — "어떤 상황에서 외로움을 느꼈나요?"
- 혼자 있는 시간이 너무 길었어요
- 대화할 사람이 없었어요
- 사람들 사이에 있어도 혼자인 느낌
- 누군가가 보고 싶었어요

**😊 뿌듯한** — "오늘 뿌듯함을 느낀 이유가 뭔가요?"
- 목표했던 걸 해냈어요
- 누군가에게 도움이 됐어요
- 오래 미뤄온 걸 드디어 했어요
- 스스로를 잘 돌봤어요

**😌 평온한** — "오늘 평온했던 이유가 뭔가요?"
- 충분히 쉬고 수면을 잘 취했어요
- 좋아하는 걸 하며 보냈어요
- 좋은 사람과 시간을 보냈어요
- 특별한 이유 없이 그냥 괜찮아요

#### 5.1.4 4단계: 자유 메모 입력

- 선택 사항
- 최대 200자
- AES-256-GCM 암호화 저장

#### 5.1.5 저장

- 저장 완료 시 트리거 알고리즘 자동 실행 (섹션 11 참고)
- 하루 1회 작성 원칙. 수정은 당일 자정 전까지 가능

### 5.2 일기 목록 / 캘린더

- 캘린더 뷰: 날짜별 이모지 표시
- 리스트 뷰: 날짜 + 감정 키워드 + 메모 미리보기
- 과거 일기 수정 불가 (당일 작성분만 수정 가능)

## 6. 루틴 탭

## 10. 긍정 미션 시스템

### 10.1 구조

단계 없이 점수제로 운영. 루틴 완료와 일기 작성 횟수를 주간 단위로 집계.

### 10.2 점수 계산

```
주간 점수 = 루틴 달성 점수(70%) + 일기 작성 점수(30%)
```

- 루틴 달성 점수: 7일 중 완료한 날 수 / 7 × 70
- 일기 작성 점수: 7일 중 작성한 날 수 / 7 × 30

### 10.3 달성 기준

- 주간 최소 달성: 7일 중 **3일 이상** 루틴 완료 + 일기 작성
- 달성 시: 해당 주 점수 적립
- 미달성 시: 점수 유지 (차감 없음, 해당 주만 적립 안 됨)

### 10.4 설계 의도

정신건강 앱에서 실패 패널티는 자책감 유발 우려가 있으므로 점수 차감 방식을 배제. 작은 성공 경험의 누적이 회복 동기로 이어지는 구조를 지향.

## 11. 루틴 트리거 알고리즘

### 11.1 개요

일기 데이터가 쌓임에 따라 사용자 상태를 자동 감지하고 루틴을 갱신하는 개인화 핵심 로직.

### 11.2 발동 조건

- 관찰 기간: 최근 **7일**
- 발동 기준: 동일 감정 키워드 **3회 이상** 등장 시

### 11.3 가중치 구조

```
트리거 점수 = mood_score 기여분(30%) + 감정 키워드 기여분(70%)

mood_score 기여분 = (5 - mood_avg) / 5 × 0.3
키워드 기여분 = (키워드 선택 횟수 / 전체 키워드 선택 횟수) × 0.7
```

- 키워드 가중치는 선택 빈도 기반으로 동적 조정

### 11.4 충돌 처리

여러 키워드가 동시에 조건을 충족하는 경우, 트리거 점수 상위 2개 키워드를 모두 커버하는 **복합 루틴** 추천.

### 11.5 재발동 주기

트리거 발동 후 **3일** 쿨다운. 쿨다운 종료 후 재발동 가능.

### 11.6 알고리즘 코드

```python
def calculate_trigger_score(diary_logs: list, days: int = 7) -> dict:
    recent_logs = diary_logs[-days:]
    keyword_freq = {}
    mood_avg = 0

    for log in recent_logs:
        mood_avg += log["mood_score"]
        for keyword in log["emotion_keywords"]:
            keyword_freq[keyword] = keyword_freq.get(keyword, 0) + 1

    mood_avg /= len(recent_logs)

    total_freq = sum(keyword_freq.values())
    keyword_weights = {k: v / total_freq for k, v in keyword_freq.items()}

    trigger_scores = {}
    for keyword, weight in keyword_weights.items():
        mood_component = (5 - mood_avg) / 5 * 0.3
        keyword_component = weight * 0.7
        trigger_scores[keyword] = mood_component + keyword_component

    return trigger_scores


def evaluate_triggers(trigger_scores: dict, freq: dict, threshold: int = 3) -> list:
    triggered = [k for k, v in freq.items() if v >= threshold]

    if len(triggered) == 0:
        return []
    elif len(triggered) == 1:
        return [triggered[0]]
    else:
        triggered_sorted = sorted(
            triggered,
            key=lambda k: trigger_scores.get(k, 0),
            reverse=True
        )
        return triggered_sorted[:2]
```
