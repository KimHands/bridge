# 로직·시드 보충 (L2·L4 + L3 가드) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 긍정 트리거 빈손 해소(L2), 미션 부분노력 보상(L4), 노출 콘텐츠 금지어 가드(L3)를 추가한다.

**Architecture:** L2는 `ROUTINE_SEEDS`에 긍정 강화 루틴 2개(tier 1-3) 추가 — 매칭 조건을 시드 리스트로 검증. L4는 미션 주간 점수를 순수함수 `compute_weekly_score`로 추출해 구성요소별 3일 게이트 적용. L3는 루틴 title·감정 질문/선택지에 기존 `assert_domain_safe`를 거는 회귀 테스트. CLAUDE.md 미션 규칙도 갱신.

**Tech Stack:** FastAPI, SQLAlchemy 2.0 async, pytest. 검증은 도커: `docker compose run --rm --no-deps api python -m pytest ...` (테스트는 순수/모킹이라 db 불필요).

- [ ] **Step 3: 순수함수 추가 + weekly 엔드포인트 적용**

`backend/app/api/v1/missions.py`에서 `_iso_week_year` 함수 정의 다음(`@router.get("/weekly"...)` 직전)에 순수함수 추가:

```python
def compute_weekly_score(routine_days: int, diary_days: int) -> tuple[int, bool]:
    """구성요소별 3일 게이트: 루틴 3일+이면 루틴점수(70%분), 일기 3일+이면 일기점수(30%분)을 각각 적립.

    한쪽만 달성해도 그 구성요소는 보상한다. 양쪽 미달이면 0(차감 없음).
    """
    routine_component = round(routine_days / 7 * 70) if routine_days >= 3 else 0
    diary_component = round(diary_days / 7 * 30) if diary_days >= 3 else 0
    weekly_score = routine_component + diary_component
    is_achieved = routine_days >= 3 or diary_days >= 3
    return weekly_score, is_achieved
```

그리고 `get_weekly_mission` 함수 내부의 기존 두 줄:

```python
    weekly_score = round(routine_days / 7 * 70) + round(diary_days / 7 * 30)
    is_achieved = routine_days >= 3 and diary_days >= 3
```

를 다음으로 교체:

```python
    weekly_score, is_achieved = compute_weekly_score(routine_days, diary_days)
```

그리고 같은 함수 아래쪽의:

```python
    total_score = historical_total + (weekly_score if is_achieved else 0)
```

를 다음으로 교체(게이트가 이미 weekly_score 내부로 이동했으므로):

```python
    total_score = historical_total + weekly_score
```

> `historical_total` 쿼리(`_ACHIEVE_ROUTINE_MIN`/`_ACHIEVE_DIARY_MIN` 필터)와 `total` 엔드포인트는 그대로 둔다 — MissionPoint 미적재로 현재 0이며, 영속화는 이번 비목표다.
