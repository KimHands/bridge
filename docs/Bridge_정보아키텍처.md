# Bridge — 정보 아키텍처 (IA)

> 작성일: 2026-04-13
> 버전: v1.0

---

## 전체 구조

```
Bridge 앱
├── 온보딩·인증
│   ├── 스플래시 (SCR-001)
│   ├── 온보딩 슬라이드 3장 (SCR-002)
│   ├── 회원가입 (SCR-003)
│   ├── 로그인 (SCR-004)
│   ├── AI 자가평가 (SCR-005)  ← 신규 가입 시 1회
│   │   ├── PHQ-9 질문지 (9문항)
│   │   └── 원인 분류 질문 (2문항)
│   └── 초기 루틴 배정 결과 (SCR-006)
│
└── 메인 앱 (하단 네비게이션)
    ├── 홈 탭 (SCR-007)
    │   ├── 대시보드
    │   │   ├── 기분 체크 (이모지 5단계)
    │   │   ├── 오늘의 루틴 카드
    │   │   └── 이번 주 리포트 요약
    │   └── 오늘의 정보 카드
    │
    ├── 일기 탭 (SCR-009)
    │   ├── 일기 목록 / 캘린더
    │   ├── 일기 작성 플로우
    │   │   ├── 1단계: 감정 키워드 선택 (SCR-008-A)
    │   │   ├── 2단계: 세부 질문 팝업 (SCR-008-B)  ← 바텀 시트
    │   │   └── 3단계: 자유 메모 입력 (SCR-008-C)
    │   └── 일기 상세 (SCR-009-D)
    │
    ├── 루틴 탭 (SCR-010)
    │   ├── 루틴 목록 (활성 루틴)
    │   └── 루틴 라이브러리 (SCR-013)  ← 모달
    │
    ├── 리포트 탭 (SCR-011)
    │   ├── 주간 리포트 (SCR-011-A)
    │   └── 월간 리포트 (SCR-011-B)
    │
    └── 마이 탭 (SCR-019)
        ├── 프로필
        ├── 알림 설정  ← 모달
        ├── 개인정보처리방침  ← 웹뷰
        ├── 이용약관  ← 웹뷰
        ├── 내 데이터 다운로드
        └── 회원 탈퇴  ← 확인 팝업
```

## 부가 기능 (하단 탭 외 접근)

```
부가 기능
├── 정신건강 정보 (SCR-012-A)
│   ├── 카테고리 필터 (전체/우울/불안/수면/관계/약물)
│   └── 정보 상세
│
├── 익명 커뮤니티 (SCR-012-B)
│   ├── 게시글 목록
│   ├── 게시글 상세
│   └── 글쓰기
│
└── 챗봇 · 병원 안내 (SCR-012-C)
    ├── 챗봇 대화
    └── 병원 찾기 연결
```

---

## 공통 모달 / 오버레이

```
공통
├── 세부 질문 팝업 (바텀 시트)  ← 일기 작성 중 감정 키워드 선택 시
├── 알림 설정 (모달)
├── 약관 상세 (웹뷰)
├── 회원 탈퇴 확인 (팝업)
├── 토스트 메시지 (성공/경고/에러)
└── 로딩 스피너 / 스켈레톤 UI
```
