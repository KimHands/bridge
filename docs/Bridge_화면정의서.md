## 1. 스플래시

### 화면 ID: SCR-001

| 항목 | 내용 |
|------|------|
| 진입 조건 | 앱 최초 실행 시 |
| 노출 시간 | 1.5초 |
| 다음 화면 | 최초 실행 → SCR-002 (온보딩), 재실행 → SCR-004 (로그인) |

### 구성 요소

| 컴포넌트 | 위치 | 설명 |
|---------|------|------|
| 앱 로고 | 화면 중앙 | Bridge 워드마크 |
| 슬로건 | 로고 하단 12px | "방치된 당신과 병원 사이의 다리, Bridge" |
| 배경 | 전체 | 오프화이트 (#F8F7FF) |

### 상태

| 상태 | 처리 |
|------|------|
| 로그인 토큰 유효 | 홈 대시보드로 자동 이동 |
| 로그인 토큰 없음 또는 만료 | 온보딩 또는 로그인으로 이동 |

## 2. 온보딩 슬라이드

### 화면 ID: SCR-002

| 항목 | 내용 |
|------|------|
| 진입 조건 | 앱 최초 설치 시 1회만 노출 |
| 다음 화면 | SCR-003 (회원가입) 또는 SCR-004 (로그인) |

### 구성 요소

| 컴포넌트 | 위치 | 설명 |
|---------|------|------|
| 슬라이드 영역 | 상단 70% | 일러스트 + 제목 + 설명 텍스트 |
| 페이지 인디케이터 | 중앙 하단 | 현재 슬라이드 위치 표시 (● ○ ○) |
| 다음 버튼 | 하단 우측 | 다음 슬라이드 이동 |
| 건너뛰기 버튼 | 상단 우측 | SCR-003으로 즉시 이동 |
| 시작하기 버튼 | 마지막 슬라이드 하단 | SCR-003으로 이동 |
| 로그인 텍스트 링크 | 시작하기 하단 | "이미 계정이 있으신가요? 로그인" → SCR-004 |

### 슬라이드 내용

| 슬라이드 | 제목 | 설명 |
|---------|------|------|
| 1장 | 내 감정을 매일 기록해요 | 키워드로 간편하게 오늘의 감정을 남겨요 |
| 2장 | 나만의 루틴으로 일상을 회복해요 | 내 상태에 맞는 루틴을 추천해드려요 |
| 3장 | 당신의 변화를 함께 확인해요 | 주간·월간 리포트로 감정 흐름을 살펴봐요 |

### 상호작용

| 동작 | 결과 |
|------|------|
| 좌우 스와이프 | 슬라이드 이동 |
| 마지막 슬라이드에서 우측 스와이프 | 변화 없음 |

## 3. 회원가입

### 화면 ID: SCR-003

| 항목 | 내용 |
|------|------|
| 진입 조건 | 온보딩 완료 또는 "회원가입" 탭 |
| 다음 화면 | 성공 → SCR-005 (AI 자가평가) |

### 구성 요소

| 컴포넌트 | 위치 | 설명 |
|---------|------|------|
| 상단 타이틀 | 상단 | "Bridge 시작하기" |
| 이메일 입력 필드 | 중앙 | 실시간 형식 유효성 검사 |
| 비밀번호 입력 필드 | 이메일 하단 | 최소 8자, 영문+숫자, 보기/숨기기 토글 |
| 비밀번호 확인 필드 | 비밀번호 하단 | 일치 여부 실시간 표시 |
| 닉네임 입력 필드 | 비밀번호 확인 하단 | 최대 10자 |
| 약관 동의 체크박스 | 닉네임 하단 | 전체 동의 / 개별 동의 토글 |
| 가입하기 버튼 | 하단 고정 | 모든 필수 항목 충족 시 활성화 |
| 로그인 텍스트 링크 | 버튼 하단 | "이미 계정이 있으신가요?" → SCR-004 |

### 약관 항목

| 항목 | 필수 여부 |
|------|---------|
| 이용약관 동의 | 필수 |
| 개인정보처리방침 동의 | 필수 |
| 민감정보(정신건강 데이터) 수집·이용 동의 | 필수 |
| 마케팅 수신 동의 | 선택 |

### 유효성 검사

| 필드 | 조건 | 에러 메시지 |
|------|------|-----------|
| 이메일 | 이메일 형식 | "올바른 이메일 형식을 입력해주세요" |
| 이메일 | 중복 | "이미 사용 중인 이메일이에요" |
| 비밀번호 | 8자 이상, 영문+숫자 | "영문과 숫자를 포함해 8자 이상 입력해주세요" |
| 비밀번호 확인 | 비밀번호 일치 | "비밀번호가 일치하지 않아요" |
| 닉네임 | 1~10자 | "닉네임은 1~10자로 입력해주세요" |

## 5. AI 자가평가

### 화면 ID: SCR-005

| 항목 | 내용 |
|------|------|
| 진입 조건 | 신규 회원가입 완료 직후 1회 |
| 다음 화면 | 완료 → SCR-006 (초기 루틴 배정 결과) |

### 5-1. 안내 화면

| 컴포넌트 | 설명 |
|---------|------|
| 안내 타이틀 | "나를 먼저 알아볼게요" |
| 안내 설명 | "간단한 질문 몇 가지로 지금 상태를 파악해요. 진단이 아닌 더 나은 루틴을 추천하기 위한 과정이에요." |
| 소요 시간 안내 | "약 3분 소요" |
| 시작하기 버튼 | 질문 시작 |

### 5-2. PHQ-9 질문 화면 (9개)

| 컴포넌트 | 위치 | 설명 |
|---------|------|------|
| 진행 바 | 상단 | N/11 진행률 표시 (PHQ-9 9개 + 원인 2개) |
| 질문 텍스트 | 중앙 상단 | 현재 문항 내용 |
| 기간 안내 | 질문 하단 | "지난 2주 동안" 고정 노출 |
| 4개 선택지 | 중앙 | 전혀 없음 / 며칠 / 일주일 이상 / 거의 매일 |
| 이전 버튼 | 하단 좌측 | 이전 문항으로 이동 |
| 다음 버튼 | 하단 우측 | 다음 문항으로 이동 (선택 후 활성화) |

> **9번 문항 특이 처리**: 1점 이상 선택 시 다음 화면 진입 전 팝업 표시
> "혹시 많이 힘드신가요? 전문가와 이야기 나눠보는 것도 좋은 방법이에요. [전문가 찾기]"
> 확인 후 계속 진행 가능

### 5-3. 원인 분류 질문 화면 (2개)

**Q1. 주원인**

| 컴포넌트 | 설명 |
|---------|------|
| 질문 | "요즘 가장 힘든 이유가 뭔가요?" |
| 선택지 | 7개 (잠을 잘 못 자고 있어요 / 학업이나 업무 때문에 지쳐요 / 미래와 진로가 막막해요 / 경제적인 걱정이 있어요 / 대인관계가 힘들어요 / 몸 상태가 안 좋아요 / 잘 모르겠어요) |
| 선택 방식 | 1개 필수 선택 |

**Q2. 부원인**

| 컴포넌트 | 설명 |
|---------|------|
| 질문 | "그 외에 신경 쓰이는 게 있나요?" |
| 선택지 | Q1 미선택 항목 + "없어요 / 건너뛸게요" |
| 선택 방식 | 1개 선택 또는 건너뛰기 |

## 6. 초기 루틴 배정 결과

### 화면 ID: SCR-006

| 항목 | 내용 |
|------|------|
| 진입 조건 | 자가평가 완료 직후 |
| 다음 화면 | SCR-007 (홈 대시보드) |

### 구성 요소

| 컴포넌트 | 위치 | 설명 |
|---------|------|------|
| 결과 타이틀 | 상단 | "OO님을 위한 루틴이 준비됐어요" |
| PHQ-9 결과 | 타이틀 하단 | 구간 명칭만 표시 (점수 미노출). 예: "지금 조금 지쳐있는 것 같아요" |
| 루틴 카드 목록 | 중앙 | 배정된 루틴 1~2개 카드 |
| 루틴 수정 안내 | 카드 하단 | "언제든지 루틴 탭에서 수정할 수 있어요" |
| 시작하기 버튼 | 하단 고정 | 홈 대시보드로 이동 |

### 루틴 카드 구성

| 컴포넌트 | 설명 |
|---------|------|
| 루틴명 | 굵은 텍스트 |
| 카테고리 태그 | 소형 뱃지 (수면 / 신체 / 마음 등) |
| 소요 시간 | 회색 텍스트 |
| 삭제 버튼 | 카드 우측 X 아이콘 (이 화면에서 즉시 삭제 가능) |

> **규제 포인트**: PHQ-9 점수 수치는 노출하지 않음. "가벼운 우울", "중등도" 등 의료적 표현 없음.
> 대신 "지금 조금 지쳐있는 것 같아요" 등 공감 언어 사용.

## 7. 홈 대시보드

### 화면 ID: SCR-007

| 항목 | 내용 |
|------|------|
| 진입 조건 | 로그인 완료 또는 하단 탭 '홈' 탭 |
| 하단 탭 | 홈 (활성) |

### 구성 요소

| 컴포넌트 | 위치 | 설명 |
|---------|------|------|
| 상단 인사말 | 최상단 | "안녕하세요, {닉네임}님 👋" + "오늘 하루도 자신을 돌봐요" |
| 알림 아이콘 | 상단 우측 | 알림 있을 시 빨간 점 표시 |
| 기분 체크 카드 | 인사말 하단 | "오늘 기분은 어때요?" + 5개 이모지 |
| 오늘의 루틴 섹션 | 기분 체크 하단 | 제목 "오늘의 루틴" + 전체보기 링크 |
| 루틴 카드 (1~2개) | 루틴 섹션 내 | 루틴명 + 완료 체크 |
| 이번 주 리포트 카드 | 루틴 하단 | 달성률 + 기분 평균 + "자세히 보기" 버튼 |
| 오늘의 정보 카드 | 최하단 | 정신건강 정보 한 줄 + "오늘의 정보" 뱃지 |
| 하단 네비게이션 | 고정 하단 | 홈 / 일기 / 루틴 / 리포트 / 마이 |

### 기분 체크 카드 상태

| 상태 | 표시 |
|------|------|
| 미선택 | 5개 이모지 모두 선택 가능 상태 |
| 선택 완료 | 선택한 이모지 강조, 나머지 흐리게. 수정 가능 |

### 루틴 카드 구성

| 컴포넌트 | 설명 |
|---------|------|
| 아이콘 | 카테고리별 아이콘 (좌측) |
| 루틴명 | 굵은 텍스트 |
| 소요 시간 또는 "오늘 미완료" | 서브 텍스트 |
| 완료 체크 버튼 | 우측 원형 체크 |
| 완료 시 배경 | 라벤더 연한 배경으로 변경 |

### 이번 주 리포트 카드 상태

| 상태 | 표시 |
|------|------|
| 데이터 충분 (7일 이상) | 달성률 % + 기분 평균 이모지 |
| 데이터 부족 | "데이터를 쌓는 중이에요 (N일 남음)" |

## 8. 일기 작성 — 1단계: 감정 키워드

### 화면 ID: SCR-008-A

| 항목 | 내용 |
|------|------|
| 진입 조건 | 하단 탭 '일기' 또는 홈에서 일기 작성 버튼 |
| 다음 화면 | SCR-008-B (세부 질문 팝업) → 선택 키워드 수만큼 반복 |

### 구성 요소

| 컴포넌트 | 위치 | 설명 |
|---------|------|------|
| 날짜 + 기분 이모지 | 상단 | 오늘 날짜 + 홈에서 선택한 이모지 표시 |
| 기분 미선택 시 | 상단 | 이모지 5개 선택 UI 노출 |
| 섹션 제목 | 이모지 하단 | "오늘 기분을 더 자세히 알려줄게요" |
| 하이라이트 키워드 | 키워드 목록 최상단 | 선택한 이모지에 맞는 2~3개 강조 노출 |
| 공통 키워드 목록 | 하이라이트 하단 | 8개 전체 노출 (칩 형태) |
| 선택 개수 표시 | 우측 상단 | "N / 2" |
| 다음 버튼 | 하단 고정 | 1개 이상 선택 시 활성화 |
| 건너뛰기 링크 | 다음 버튼 하단 | 키워드 없이 메모만 작성 |

### 키워드 칩 상태

| 상태 | 표시 |
|------|------|
| 기본 | 라이트 그레이 배경, 검정 텍스트 |
| 선택됨 | 라벤더 배경, 흰색 텍스트 |
| 2개 선택 후 나머지 | 흐리게 (비활성) |
| 하이라이트 키워드 | 라벤더 테두리 + 살짝 강조 |

## 9. 일기 작성 — 2단계: 세부 질문 팝업

### 화면 ID: SCR-008-B

| 항목 | 내용 |
|------|------|
| 형태 | 바텀 시트 (Bottom Sheet) |
| 진입 조건 | 감정 키워드 선택 후 자동 팝업 |
| 선택 키워드 2개 시 | 각각 순차적으로 바텀 시트 등장 |

### 구성 요소

| 컴포넌트 | 위치 | 설명 |
|---------|------|------|
| 선택한 감정 키워드 | 시트 상단 | 예: "불안한" (강조 표시) |
| 세부 질문 | 키워드 하단 | 감정별 고유 질문 텍스트 |
| 답변 선택지 | 중앙 | 4~5개 라디오 버튼 리스트 |
| 확인 버튼 | 시트 하단 | 선택 후 활성화 |
| 닫기 버튼 | 우측 상단 | 선택 없이 닫기 (상황 키워드 미저장) |

### 질문 목록 요약

| 감정 키워드 | 질문 |
|-----------|------|
| 우울한 | 지금 가장 힘든 게 뭔가요? |
| 무기력한 | 무기력함이 어디서 오는 것 같아요? |
| 불안한 | 무엇 때문에 불안했나요? |
| 초조한 | 오늘 초조함을 느낀 상황은요? |
| 짜증나는 | 오늘 짜증이 났던 원인이 뭔가요? |
| 외로운 | 어떤 상황에서 외로움을 느꼈나요? |
| 뿌듯한 | 오늘 뿌듯함을 느낀 이유가 뭔가요? |
| 평온한 | 오늘 평온했던 이유가 뭔가요? |
